# AI-Iris-Flower-Classification
Machine learning classification project using the Iris dataset and K-Nearest Neighbors (KNN) algorithm.

# 🌸 Iris Flower Classification Using Machine Learning

## About the Project
This project uses supervised machine learning to classify Iris flowers into three species:
Setosa, Versicolor, and Virginica.

The model uses the K-Nearest Neighbors (KNN) algorithm to predict flower species
based on four measurements.

## Dataset
- Total samples: 150
- Classes: 3
- Features: 4
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning Workflow
1. Load the Iris dataset
2. Explore and prepare the data
3. Scale the features using StandardScaler
4. Split the data into training and testing sets
5. Train the KNN classification model
6. Evaluate the model
7. Generate predictions and visualizations

## Algorithm
K-Nearest Neighbors (KNN)

## Model Performance
Test accuracy: 96.67%

## Results
The model successfully classifies Iris flower species
using their physical measurements.

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the model:

```bash
python src/train_model.py
```
